# Карточка проекта (ЛЗ 1, часть 5)

> Черновик: заказчик обезличен; перед сдачей заменить на согласованного контактного человека.

| Поле | Содержание |
|---|---|
| Название | «Практика» — система приёма и маршрутизации заявок студентов на практику и вакансий от партнёров карьерного центра |
| Заказчик | Руководитель карьерного центра университета; решения по содержанию — методист центра |
| Проблема | Заявки и предложения работодателей собираются вручную по почте и в Excel. Студент не видит статус, дедлайны отчётов никто не отслеживает автоматически, часть писем теряется |
| Как это заметно | В пик (сентябрь–октябрь) 30–40 заявок в неделю; сведение в таблицу ≈ 4 ч в неделю; несколько жалоб за семестр на «пропавшую» заявку (уточнить у заказчика) |
| Ожидаемый эффект | Время на сведение 4 → 1 ч/нед; доля заявок с прослеживаемым статусом 0 → 100 %; дедлайн отчёта виден студенту и куратору заранее |
| Границы | Входит: подача заявки, маршрутизация, статусы, уведомления, отчёт по срокам. Не входит: интеграция с ИС успеваемости, ЭЦП, мобильное приложение |
| Команда | Бекмағанбет Әлібек — PM, коммуникация с заказчиком, разработка; Зият Нүркен — аналитика, требования, тестирование и CI |
| Риск №1 | Методист — единственный источник требований и приёмки. Владелец — Бекмағанбет Әлібек; триггер — две недели без ответа |
