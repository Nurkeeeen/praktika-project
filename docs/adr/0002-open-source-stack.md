# ADR-002: Открытый стек и разработка силами команды курса

- Статус: предложено (утверждается спонсором вместе с бизнес-кейсом ЛЗ 3)
- Дата: 2026-09-24
- Кто принял: команда проекта; утверждает спонсор

## Контекст

Бизнес-кейс ЛЗ 3 ([lz3-business-case.md](../lz3-business-case.md), модель — [finance/](../../finance/)) сравнил пять
вариантов за 3 года. Годовой эффект проекта — около 479 тыс. ₸ (222 ч времени персонала). При таком масштабе
стоимость лицензий и заказной разработки быстро превышает эффект.

## Рассмотренные варианты

1. **Ничего не делать** — NPV 0, но заявки теряются, ПДн остаются в почте.
2. **Битрикс24 «Стандартный»** — NPV −0,8 млн ₸, закрывает ~80 % процесса, вопрос локализации ПДн.
3. **Windows Server + SQL Server, подрядчик** — NPV −6,4 млн ₸; лицензии 4,7 млн ₸ ≈ 10 годовых эффектов.
4. **Linux + PostgreSQL + Python, подрядчик** — NPV −1,7 млн ₸.
5. **Linux + PostgreSQL + Python, студенческая команда** — NPV +0,18 млн ₸, ROI +29 %.

## Решение

Вариант 5: Python/FastAPI + PostgreSQL на Linux-VPS в Казахстане (hoster.kz, 1 vCPU / 2 ГБ), разработка MVP силами
команды курса, поддержка с февраля 2027 — ИТ-отдел (до 4 ч/мес).

## Последствия

- \+ Нет лицензионных платежей и привязки к вендору; данные хранятся в РК.
- \+ Кодовая база и данные принадлежат университету.
- − Запас прочности меньше 20 %: при эффекте ниже 82 % расчётного NPV отрицательный — допущения проверяем до недели 5.
- − Без письменного согласия ИТ-отдела на поддержку запуск не делаем (условие go / no-go).
